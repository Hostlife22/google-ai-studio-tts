# Voices in Gemini Flash TTS (AI Studio)

The Speaker settings panel searches **2,000+ voices** (`input[aria-label="Search voices"]`) with filters Language / Gender / Pitch / Style / Use case. Verified live 2026-10-15. Names are case-sensitive; always confirm a name via search before using it.

## Defaults

- New dialog: Speaker 1 = **Fola**, Speaker 2 (second block) = **Rami**.
- Two-host podcast baseline: **Puck** (Upbeat) + **Zephyr** (Bright), or the Podcast group below.

## Style instead of Director's note

Audio Profile and Director's note (Style/Pace/Accent dropdowns) were removed from the voice panel. Steer delivery with the per-block **Style** chip (free text or presets Whisper / Friendly / Narration / Promote / Podcast) — see audio-tags.md.
